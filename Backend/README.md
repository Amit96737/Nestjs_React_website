# NestJS Practice Project

A basic NestJS backend project for practice.

## Tech Stack

* NestJS
* TypeScript
* PostgreSQL
* Prisma
* Redis
* SMTP / Nodemailer
* JWT
* Swagger

## Features

* User registration
* Password hashing
* Email OTP verification
* Redis OTP storage
* SMTP email
* User login
* JWT token
* Swagger documentation

## APIs

```text
POST /users
POST /users/verify-otp
POST /users/sign-in
```

## Run Project

```bash
npm install
npm run start:dev
```

Server:

```text
http://localhost:3000
```

Swagger:

```text
http://localhost:3000/api/docs
```
